# sp-plan Process

## Trigger
Enter `sp-plan` after the design is approved.

## Inputs
- approved design
- known constraints
- target repository context

## Steps
1. Restate scope and non-goals.
2. Break work into milestones.
3. Split each milestone into executable tasks.
4. Attach verification to every task.
5. Record risks and open questions.

## Handoff
Hand off to `sp-implement` only when the plan is executable without redoing design.
