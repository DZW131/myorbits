# Examples

These examples support the authoring guides under `docs/`.

- `issues_orbit_source_branch`
  - Target-state source branch example for authoring an orbit and publishing it later.
- `issues_orbit_template_branch`
  - Target-state published orbit template example.

Both examples describe the same `issues` orbit so readers can compare:

- authoring-only files
- published payload
- brief / orchestration inputs
- the closed-loop shape of one orbit
